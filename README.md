# Responsive E-Commerce Platform

A production-ready client-side e-commerce web application developed with modern JavaScript (ES6+), semantic HTML5, and responsive CSS3.

## Key Features
- **Dynamic Shopping Cart:** State management using vanilla JavaScript with real-time subtotal, GST (18%), and order total calculation.
- **Client-Side Form Validation:** Regex-driven validation for name, email format, and 10-digit mobile verification with instant visual error feedback.
- **Search & Category Filtering:** Instant search bar and category selection via live DOM updates without external dependencies.
- **Responsive Layout:** Mobile-first layout featuring CSS Grid and Flexbox for seamless cross-device compatibility.

## Tech Stack
- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **FontAwesome Icons**
